# 首次打开 / First launch

## 简体中文

从 GitHub 下载的版本尚未经过 Apple 公证。首次打开时 macOS 可能显示“未打开‘鼠标电量’”。这表示 macOS 无法验证开发者身份，并不表示应用被判定为恶意软件。

1. 将“鼠标电量.app”拖入“应用程序”。
2. 在 Finder 中按住 **Control** 点击“鼠标电量”，选择“打开”，再确认“打开”。
3. 如果仍只显示“移到废纸篓”，进入“系统设置 → 隐私与安全性”，滚到页面下方，找到此应用被拦截的提示，点击“仍要打开”。
4. 第一次启动后，在“系统设置 → 隐私与安全性 → 输入监控”中允许“鼠标电量”。

完成后，应用可从“应用程序”正常启动。

## English

The GitHub build has not been notarized by Apple. At first launch, macOS may say it cannot open MouseBattery. This means macOS cannot verify the developer’s identity; it does not mean the app was identified as malware.

1. Drag `鼠标电量.app` to Applications.
2. In Finder, Control-click the app, choose **Open**, then confirm **Open** again.
3. If only **Move to Trash** is offered, go to **System Settings → Privacy & Security**, scroll to the bottom, locate the blocked-app notice, and click **Open Anyway**.
4. After the first launch, allow MouseBattery in **System Settings → Privacy & Security → Input Monitoring**.

The app can then be opened normally from Applications.
